CREATE TABLE IF NOT EXISTS outbox (

### 문제 1: Connection Refused (Auction Service)

**증상**:
```
ERRO[0000] Get "http://localhost:8084/api/v1/auctions": dial tcp [::1]:8084: connect: connection refused
```

**해결**:
1. 서비스 실행 확인
   ```bash
   lsof -i :8084
   kubectl get pods -n biddy | grep auction
   ```

2. 포트 포워딩 재시작
   ```bash
   pkill -f "port-forward.*8084"
   kubectl port-forward -n biddy svc/auction-service 8084:8080
   ```

### 문제 2: 401 Unauthorized (인증 필요)

**증상**:
```
[Test 1-2] Exact minimum bid: 105000 (expected: accept)
  ⚠ Need authentication (status: 401)
```

**해결**:
이것은 예상된 동작입니다. 실제 입찰 API는 JWT 인증이 필요합니다.

**테스트 스크립트 수정** (선택사항):
```javascript
// JWT 토큰 생성 후 사용
const token = 'Bearer eyJhbGc...';

const exactBidResponse = http.post(
    `${AUCTION_BASE_URL}/api/v1/auctions/${auctionId}/bids`,
    JSON.stringify({...}),
    {
        headers: {
            'Content-Type': 'application/json',
            'Authorization': token
        }
    }
);
```

### 문제 4: Kafka 토픽 없음

**증상**:
```
WARN  org.apache.kafka.clients.NetworkClient - [Producer] Error while fetching metadata
```

**해결**:
```bash
# EC2에서 Kafka 토픽 생성
ssh ec2-user@<EC2-IP>

docker exec -it biddy-kafka kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --create \
  --topic auction-events \
  --partitions 3 \
  --replication-factor 1

# 토픽 확인
docker exec -it biddy-kafka kafka-topics.sh \
  --bootstrap-server localhost:9092 \
  --list
```
