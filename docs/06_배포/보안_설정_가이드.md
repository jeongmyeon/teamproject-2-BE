# 보안 설정 가이드

> Biddy 플랫폼 프로덕션 배포를 위한 필수 보안 설정

**업데이트:** 2026-07-23
**중요도:** 🔴 Critical

---

## 🚨 개요

본 가이드는 Biddy 플랫폼의 **하드코딩된 비밀번호 및 키를 안전하게 관리**하기 위한 필수 설정을 다룹니다.

**⚠️ 경고:**
- 예제 코드의 비밀번호/키는 **개발/테스트 환경 전용**입니다
- **프로덕션 배포 시 반드시 변경**해야 합니다
- 변경하지 않으면 심각한 보안 위험이 발생합니다

## 🔧 보안 강화 방법

### 1. Grafana 비밀번호 변경

#### 방법 A: kubectl로 직접 변경 (권장)

```bash
# 강력한 비밀번호 생성
GRAFANA_PASSWORD=$(openssl rand -base64 20)

# Secret 업데이트
kubectl create secret generic grafana-secrets \
  --from-literal=admin-password="$GRAFANA_PASSWORD" \
  -n biddy-monitoring --dry-run=client -o yaml | kubectl apply -f -

# Grafana 재시작
kubectl rollout restart deployment/grafana -n biddy-monitoring

# 비밀번호 안전하게 저장
echo "Grafana 비밀번호: $GRAFANA_PASSWORD" >> ~/.biddy_secrets.txt
chmod 600 ~/.biddy_secrets.txt
```

#### 방법 B: 환경 변수 사용

```bash
# .env 파일 생성
cat > ~/.biddy_monitoring.env <<EOF
GRAFANA_ADMIN_PASSWORD=$(openssl rand -base64 20)
EOF

# 배포 시 환경 변수 로드
source ~/.biddy_monitoring.env
envsubst < k8s/monitoring/grafana.yaml | kubectl apply -f -
```

### 2. PostgreSQL 비밀번호 변경

```bash
# 강력한 비밀번호 생성
POSTGRES_PASSWORD=$(openssl rand -base64 20)

# ConfigMap 또는 Secret 업데이트
kubectl create secret generic postgres-secret \
  --from-literal=POSTGRES_PASSWORD="$POSTGRES_PASSWORD" \
  -n biddy --dry-run=client -o yaml | kubectl apply -f -

# 모든 서비스에 반영
kubectl rollout restart deployment -n biddy-services
```

**⚠️ 주의:** PostgreSQL 비밀번호 변경 시 데이터베이스와 모든 서비스의 설정을 동시에 업데이트해야 합니다.

### 3. JWT Secret 변경

```bash
# 최소 32자 이상의 랜덤 문자열 생성
JWT_SECRET=$(openssl rand -base64 32)

# biddy-secret 업데이트
kubectl create secret generic biddy-secret \
  --from-literal=JWT_SECRET="$JWT_SECRET" \
  -n biddy --dry-run=client -o yaml | kubectl apply -f -

# Member Service 재시작
kubectl rollout restart deployment/member -n biddy-services
```

**⚠️ 주의:** JWT Secret 변경 시 기존 로그인 토큰이 모두 무효화됩니다.

### 4. Toss Payments 실제 키 발급

#### 4-1. Toss Payments 가입

1. https://www.tosspayments.com 접속
2. 회원가입 및 사업자 등록
3. **개발자 센터** → **API 키 관리**

#### 4-2. API 키 발급

```bash

TOSS_PAYMENTS_SECRET_KEY=live_sk_YYYYYYYYYYYYYYYY
```

#### 4-3. Kubernetes Secret 업데이트

```bash

  --from-literal=TOSS_SECRET_KEY="live_ck_XXXXXXXXXXXXXXXXXX" \
```

## 🔐 비밀번호 관리 Best Practices

### 1. 강력한 비밀번호 생성 규칙

- **최소 길이:** 16자 이상
- **복잡도:** 대문자, 소문자, 숫자, 특수문자 포함
- **무작위성:** `openssl rand -base64` 사용 권장

**생성 예제:**
```bash
# 20자 비밀번호
openssl rand -base64 20

# 32자 비밀번호
openssl rand -base64 32

# 16진수 64자 비밀번호
openssl rand -hex 32
```

### 2. 비밀번호 저장 방법

#### 권장: Kubernetes Secret

```bash
# Secret 생성 (Base64 인코딩 자동)
kubectl create secret generic my-secret \
  --from-literal=password="YOUR_STRONG_PASSWORD"
```

#### 권장: 환경 변수 파일 (로컬 개발)

```bash
# .env 파일 생성
cat > ~/.biddy.env <<EOF
GRAFANA_PASSWORD=$(openssl rand -base64 20)
POSTGRES_PASSWORD=$(openssl rand -base64 20)
JWT_SECRET=$(openssl rand -base64 32)
EOF

# 파일 권한 제한 (소유자만 읽기)
chmod 600 ~/.biddy.env

# Git에서 제외
echo ".env" >> .gitignore
echo "*.env" >> .gitignore
```

#### 권장: Secrets Manager (프로덕션)

- **AWS Secrets Manager**
- **HashiCorp Vault**
- **Azure Key Vault**
- **Google Secret Manager**

### 3. 비밀번호 순환 (Rotation)

주기적으로 비밀번호를 변경하세요:

| 항목 | 권장 순환 주기 |
|------|---------------|
| Grafana 관리자 비밀번호 | 3개월 |
| PostgreSQL 비밀번호 | 6개월 |
| JWT Secret | 12개월 |
| API 키 (Toss, OpenAI) | 필요 시 |

## 🔍 보안 검증

### 1. 비밀번호 강도 확인

```bash
# 비밀번호 길이 확인
echo -n "admin1234" | wc -c  # 9자 (❌ 약함)
echo -n "$(openssl rand -base64 20)" | wc -c  # 28자 (✅ 강함)
```

### 2. Secret 노출 검사

```bash
# Git 히스토리에서 비밀번호 검색
git log -S "admin1234" --all

# 현재 파일에서 하드코딩된 비밀번호 검색
grep -r "password.*=.*['\"].*['\"]" k8s/
```

### 3. Kubernetes Secret 확인

```bash
# Secret 목록 확인
kubectl get secrets -n biddy-monitoring
kubectl get secrets -n biddy

# Secret 값 확인 (Base64 디코딩)
kubectl get secret grafana-secrets -n biddy-monitoring -o jsonpath='{.data.admin-password}' | base64 -d
```
